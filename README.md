# Канбан-доска задач (SkyWords)

Проект веб-приложения для управления задачами в формате канбан-доски. 
Реализован на React с функциональными компонентами и хуками.

## Функциональность
- Отображение задач по колонкам (статусам): Без статуса, Нужно сделать, В работе, Тестирование, Готово
- Создание новой задачи 
- Просмотр и редактирование задачи 
- Выход из аккаунта 
- Меню пользователя с переключением по клику на имя
- Имитация загрузки данных с задержкой

## Технологии
- React (useState, useEffect)
- JSX, CSS (адаптивная вёрстка)
- Работа с модальными окнами и массивами данных

## Установка и запуск
1. Клонируйте репозиторий:
  git clone [URL репозитория]
2. Перейдите в папку проекта:
  cd [название папки]
3. Установите зависимости:
  npm install
4. Запустите проект в режиме разработки:
  npm run dev
Откройте http://localhost:5173 (или другой порт, указанный в терминале).
