# Канбан-доска задач (SkyWords)

Проект веб-приложения для управления задачами в формате канбан-доски.

## Функциональность

- Регистрация и авторизация через API
- Создание, просмотр, редактирование и удаление задач
- Перемещение задач между колонками с помощью drag-and-drop
- Выбор даты выполнения через интерактивный календарь с возможностью листать месяцы
- Переключение светлой/тёмной темы (сохранение выбора)
- Уведомления об операциях с задачами (react-toastify)
- Скелетоны загрузки вместо статичного текста
- Валидация форм с подсветкой полей
- Обработка ошибок сервера и сети
- Адаптивный дизайн
- Страница 404 со ссылкой на главную

## Дополнительные фичи

- Drag-and-drop перенос задач между статусами
- Сохранение темы в localStorage
- Анимированные скелетоны во время загрузки
- Интерактивный календарь с возможностью перелистывания месяцев и выбора любой даты

## Технологии

- React, React Router v6
- Styled Components
- Axios
- @hello-pangea/dnd
- React-Toastify

## Установка и запуск

1. Клонируйте репозиторий:
   git clone [URL репозитория]
2. Перейдите в папку проекта:
   cd [название папки]
3. Установите зависимости:
   npm install
4. Запустите проект в режиме разработки:
   npm run dev
   Откройте http://localhost:5173 (или другой порт, указанный в терминале).
